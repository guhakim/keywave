글에 꼭 쓸 설명:
- **경락가 = 경매(도매) 가격**이에요. 시장 가게에서 사는 **소매가는 이것보다 비싸요.** (가게마다 다름)
- "**12미**" = 1kg에 12마리 정도. **숫자가 클수록 작은 전어** → 같은 1kg이어도 싸요.
- **활어(살아있는 것)는 회용, 선어(죽은 것)는 구이용**이라 가격 차이가 커요.
- 시세는 **날마다, 그날 들어온 양에 따라** 바뀌어요 → 가기 전에 그날 시세를 직접 확인하는 법을 알려주는 게 글의 핵심.
- 9월 중순 3.6만 원대 → 10월 중순 2만 원대로 내려옴 (같은 사이트 실제 기록). 단, **날마다 산지·크기가 달라서 "얼마 내렸다"는 대략적인 흐름**으로만 말하기.

> ❗ 지금 글에 넣을 수 있는 건 **도매(경락) 가격**뿐이에요. **소매가(가게에서 파는 값)·회 뜨는 값·상차림비**는 직접 가서 보거나 산 값으로만 써 주세요. 제가 숫자를 지어내지 않았어요.

## 3. 독자와 각도

- **각도**: "블로그 후기 가격" 대신 **공식 경매 시세를 직접 보는 법** + **크기(미수)로 값 읽는 법** + **현장 체크리스트**

## 5. 글 구조 (기존 블로그 /35·/40 형식, 모바일용 짧은 문단)

1. **도입** (2~3줄): "전어 사러 가기 전, 오늘 시세부터 확인하세요" + 표지 사진
2. **📌 이 글 한눈에 보기** (표): 확인처 · 1kg 시세 범위(경락가) · 회/구이 고르는 법 · 체크리스트
3. **1. 최근 수산시장 전어시세 현황 비교**
   - 위 표(9/15 → 10/12 → 10/19) + "경락가 ≠ 소매가" 안내
   - **노량진 경락시세 보는 법 3단계** (사이트 접속 → 어종 '전어' → 날짜 입력·조회) — 화면 캡처
   - 💬 **직접 간 날 소매가** (가게 가격표 사진 + 실제 산 값) ← 직접 채우기
4. **2. 신선한 횟감용 전어를 고르는 요령**
   - 눈이 맑고 볼록 / 아가미 선홍색 / 비늘·은빛 광택 / 배가 단단 / 수조에서 활발히 헤엄
   - "💡 이런 전어면 성공!" 상자
5. **3. 회와 구이용 크기별 가격 차이와 추천**
   - 미수(10미·12미·18미) 설명 표 + 실제 경락가 비교 (13/14미 27,000원 vs 18/19미 13,200원)
   - 회: 활전어, 너무 크지 않은 크기 / 구이: 선어도 OK, 통통한 것
   - 1인 몇 마리? → 일반적인 안내만 하고 "가게에 물어보기"
6. **4. 전어 구매 시 확인할 체크리스트** (체크박스 목록)
   - 가기 전 오늘 경락시세 확인 / 1kg 가격·마릿수 확인 / 활어·선어 구분 / 회 뜨는 값·상차림비 따로인지 / 무게 다는 것 직접 보기 / 카드·현금 가격 차이
7. **FAQ**: 전어 제철은 언제까지? · 경락가와 소매가 차이는? · 뼈째회(세꼬시)와 회 차이?
8. **같이 보면 좋은 글**: /40 LA갈비찜, /39 깍두기 등
9. (선택) 쿠팡 상품: 회칼·초장·생선구이팬 등 — 지난번처럼 상자 + 카드 형식, 파트너스 문구 맨 위

## 6. 사진 기획 ⭐

체크포인트가 **"직접 방문하거나 구매한 사진"**이라서, **시세·가격이 보이는 사진은 꼭 직접 찍어야 해요.**

| # | 위치 | 사진 | 직접 / AI |
|---|---|---|---|
| 1 | 표지 | 수조 속 은빛 전어 떼 또는 얼음 위 전어 | **직접** 추천 (AI 가능: 일반 이미지) |
| 2 | 소제목1 | **가게 가격표** (1kg 가격이 보이게) | **꼭 직접** |
| 3 | 소제목1 | 노량진 경락시세 사이트 **화면 캡처** (전어 조회 결과) | 캡처 (제가 만들어 드릴 수 있어요) |
| 4 | 소제목1 | 시세 비교 그래프/카드 (9/15·10/12·10/19 실제 숫자) | 제가 데이터로 만들기 |
| 5 | 소제목2 | 전어 **눈·아가미 클로즈업** (신선한 것) | **직접** 추천 (AI 가능) |
| 6 | 소제목2 | 수조에서 헤엄치는 활전어 | **직접** |

| 8 | 소제목3 | 썰어 놓은 전어회 / 구운 전어구이 | 직접 (AI 가능) |

- **꼭 직접**: 2, 6, 9 (가격·현장 증거) → 이것 없이는 체크포인트 "직접 방문 사진"을 못 채워요
- **AI로 대신 가능**: 1, 5, 8 (일반 설명용) → 그 경우 "※ 사진은 이해를 돕기 위해 AI로 만든 이미지예요" 표시
- **제가 바로 만들 수 있는 것**: 3(사이트 캡처), 4(실제 시세 카드)
- 사진 팁: 가로 사진, 가격표는 글씨가 읽히게 가까이, 얼굴 나온 상인은 허락받거나 가리기
